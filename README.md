# 🖼️ Image Carousel / Slider

A responsive image carousel built using HTML5, CSS3, and JavaScript.

## Features

- Five image slides.
- Next and previous navigation buttons.
- Automatic slide rotation every 3 seconds.
- Auto-rotation pauses when hovering over the carousel.
- Slide indicators for direct navigation.
- Smooth CSS fade transitions.
- Wraps from the last slide to the first and vice versa.
- Responsive layout for desktop and mobile.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` — Carousel structure and images
- `style.css` — Layout, responsive design, and transitions
- `script.js` — Slide navigation, indicators, and timer

## How to Use

1. Open the page to view the image carousel.
2. Use the arrow buttons to move between images.
3. Click an indicator to jump to a specific slide.
4. Hover over the carousel to pause automatic rotation.
5. Move the pointer away to resume automatic rotation.
